# Amazon Clone (HTML & CSS)

A responsive Amazon-inspired homepage built using only HTML and CSS — no JavaScript, no frameworks.

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

---

## Overview

This project is a front-end clone of the Amazon homepage, built purely with HTML and CSS.
The main goal is to practice modern UI design principles, layout structuring, and responsive
web development using media queries.

---

## Features

- 📱 Fully responsive design — Mobile, Tablet, and Desktop
- 🛍️ Amazon-like homepage UI
- 🧱 Clean and well-structured layout
- 🎨 Built using only HTML & CSS
- 📐 Media queries for smooth responsiveness
- ✅ Beginner-friendly front-end project

---

## Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Page structure and layout |

## Getting Started

### Prerequisites
Just a modern web browser — no installs required.

### Run Locally

1. Clone the repository:
```bash
   git clone https://github.com/fizzakiran372-svg/amazon-clone.git
```
2. Navigate into the project folder:
```bash
   cd amazon-clone
```
3. Open `index.html` in your browser — or simply double-click the file in your file explorer.
